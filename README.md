# global-directory

Instantly share any local folder publicly via Cloudflare Tunnel with a beautiful file browser UI.

## Install

    pip install global-directory

Requires cloudflared:
- Mac: brew install cloudflared
- Linux: https://github.com/cloudflare/cloudflared/releases
- Windows: winget install Cloudflare.cloudflared

## Usage

    cd /any/folder
    global-directory start
    global-directory stop

## Features

- Public URL via Cloudflare Tunnel (no account needed)
- Beautiful file browser UI
- Filter by type, extension, search
- Grid and list view
- File downloads
- QR code in terminal
- Breadcrumb navigation
